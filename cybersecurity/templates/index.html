SECURITY ACADEMY

Cybersecurity Learning Hub

Explore practical security concepts through short lessons, examples, warning signs and defensive checklists.

01
BEGINNER

Phishing & Social Engineering

Learn how attackers use urgency, impersonation and deceptive links to influence users.

Study notes
  • Check the real domain, not just the page branding.
  • Be cautious with urgent payment or password requests.
  • Use a known bookmark or trusted channel to verify unusual requests.
02
BEGINNER

Authentication

Understand passwords, passphrases, password managers and multi-factor authentication.

Study notes
  • Prefer long, unique credentials.
  • Use MFA for important accounts.
  • Never reuse a sensitive password across services.
03
INTERMEDIATE

Cross-Site Scripting

Understand why untrusted data must be safely handled before it reaches an HTML or script context.

Study notes
  • Context-aware output encoding is important.
  • Content Security Policy can add another layer.
  • Do not treat client-side validation as the only defense.
04
INTERMEDIATE

Sessions & CSRF

Learn how session cookies work and why state-changing requests need anti-CSRF protections.

Study notes
  • Use secure session-cookie settings.
  • Protect state-changing requests with an appropriate CSRF defense.
  • Rotate or invalidate sessions when risk requires it.
05
INTERMEDIATE

HTTP Security Headers

Explore CSP, HSTS, X-Content-Type-Options, Referrer-Policy and Permissions-Policy.

Study notes
  • Headers should match the application's actual requirements.
  • HSTS is designed for HTTPS deployments.
  • CSP should be tested carefully before enforcement.
06
ADVANCED

SSRF & Internal Networks

Understand why server-side URL fetching can reach destinations the browser cannot directly access.

Study notes
  • Validate and normalize destinations.
  • Use network egress controls and allowlists where appropriate.
  • Pay special attention to loopback, private, link-local and cloud metadata services.
07
ADVANCED

Cryptography Basics

Separate hashing, encryption and encoding, and learn where salts and modern password hashing fit.

Study notes
  • Hashing is not reversible encryption.
  • Password storage should use a dedicated password-hashing scheme.
  • TLS protects data in transit when correctly configured.
08
ADVANCED

Detection & Incident Response

Learn how useful logs, alerts and response procedures turn suspicious activity into actionable evidence.

Study notes
  • Record useful security events without collecting unnecessary secrets.
  • Correlate events across systems where possible.
  • Have a documented containment and recovery process.
